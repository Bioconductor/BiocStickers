# `BiocStaging` GitHub organization logo

This logo is used in the [BiocStaging GitHub organization](https://github.com/BiocStaging), where packages under review for addition to the Bioconductor package suite temporarily live.

* Maintainer: Hugo Gruson
* License: Creative Commons Attribution
  [CC-BY](https://creativecommons.org/licenses/by/4.0/).

This logo uses the colour scheme and look of a roadworks sign and the Bioconductor note is drawn with a black gradient. Both elements indicate packages in this organization are work in progress towards inclusion in the Bioconductor package suite.
